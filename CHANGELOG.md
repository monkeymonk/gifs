# Changelog

## 0.0.1

Initial release.

- 11ty v3 static site generator with vanilla JS web components and plain CSS
- Folder-based GIF categorization (reactions, celebrations, actions, misc)
- Search by name, tag, or keyword
- Filter by category/subcategory tags (collapsible)
- Favorites (localStorage)
- Lightbox with prev/next navigation and keyboard shortcuts
- Command palette (Cmd+K) with live search
- Copy as URL, Markdown, or HTML
- Download GIFs
- Dark/light theme toggle
- Responsive CSS columns masonry layout
- Canvas-based freeze frame (animates on hover)
- GitHub Actions deploy to GitHub Pages
- Screenshot generation via Playwright (`npm run screenshots`)
